# BioArcade — Yasal / Legal

The privacy policy and terms of use for the **BioArcade: Endless Mini Games**
mobile game, published as a GitHub Pages site.

- Gizlilik Politikası / Privacy Policy → [privacy.html](privacy.html)
- Kullanım Koşulları / Terms of Use → [terms.html](terms.html)

Each page carries both Turkish and English with a switch at the top, because the
stores ask for one URL per document.

**These pages are generated.** The source texts live with the game and the site
is built from them by `tools/build_legal_site.sh`; editing the HTML here by hand
would be undone the next time it runs.
